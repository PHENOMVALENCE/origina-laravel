# Manufacturing and serialized verification

## Data model

ManufacturingBatch references a product, unique code, manufacturing/expiry dates, status and quality notes. ProductUnit references the batch, a unique human-readable serial, a 256-bit random verification token and status. Tokens use `random_bytes(32)` and are hidden from ordinary serialization.

Lifecycle: batch draft → quality_review → released. Units begin created and become active at release unless revoked. Unit generation is allowed only in draft. Release rejects an expired batch. Revocation is permanent through the delivered UI. These records do not change commerce inventory automatically; reconcile actual saleable stock separately.

## Labels

Private `/admin/batches/{id}/export` streams serial and verification URL CSV for an approved printing workflow. Private `/admin/units/{id}/label` renders a local SVG QR generated by BaconQrCode. Inspect print size and scan quality on the physical substrate before production. Exports and individual label access are audited and no-store.

Verification URL: `/verify/{64-character-hex-token}`. Do not expose unreleased tokens outside the packaging workflow. Restrict and dispose of label exports according to operational policy.

## Public response

A positive result requires an existing active unit in a released, nonexpired batch. The page shows product, serial, batch, manufacturing/expiry dates and scan count. Unknown/inactive/revoked/expired codes share a conservative invalid response. The page is throttled, noindex and no-store.

Repeated scans trigger a visible caution, not an automatic fraud accusation. A copied genuine code can still resolve to a valid record; the system cannot independently certify the physical contents. The page explains this limitation.

## Privacy

Scans store a keyed daily visitor hash and timestamps, not raw IP or user-agent/location data. A hash is pseudonymous rather than guaranteed anonymous. Scheduled cleanup removes scan records after 90 days; run Laravel's scheduler every minute. Aggregate scan counts therefore cover retained records, not necessarily lifetime scans. No geolocation or health records are collected.

## Future controls

Tamper-evident packaging, controlled printer custody, inventory reconciliation, evidence file references, external append-only audit retention and reasoned fraud review can strengthen the system. No blockchain/NFC/AI fraud capability is claimed.
