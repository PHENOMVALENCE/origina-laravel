# ORIGINA — Laravel

Laravel implementation of ORIGINA™, an evidence-led, multi-divisional scientific institution originating in Dar es Salaam, Tanzania.

This repository is being rebuilt deliberately from the existing `PHENOMVALENCE/origina-next` project. The initial phase is **frontend-only**: establish the engineering baseline, documentation, design system, Blade view architecture, accessibility, performance, security defaults, and visual direction before any application backend, commerce, authentication, database, payment, or administration logic is introduced.

> Working implementation lives on feature branches and reaches `main` through pull requests.
